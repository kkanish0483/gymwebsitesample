# TITAN FORGE GYM - Premium Mobile-First Fitness Website

A modern, high-performance, mobile-first website for **Titan Forge Gym** engineered with a premium dark aesthetic (deep onyx black, refined charcoal `#111116`, and high-voltage orange `#ff6b00`).

## ⚡ Highlights & Mobile-First Features

- **Mobile Hero Experience**: Dynamic viewport height handling (`100svh`/`100dvh`), high-definition fitness athlete imagery, multi-stop dark vignette gradient ensuring headline text never clashes with the athlete, and stacked full-width CTA buttons.
- **App-Grade Slide-in Drawer**: Smooth slide-in navigation panel with frosted glassmorphic backdrop, instant close-on-tap, and background scroll locking (`overflow: hidden; touch-action: none;`).
- **Touch-Swipeable Disciplines Rail**: Native CSS horizontal snap cards (`scroll-snap-type: x mandatory`) with real-time active indicator dot synchronisation.
- **Vertical Membership Stacks**: Stacked pricing tiers on mobile with the **Pro Athlete** plan highlighted by glowing orange borders and "MOST POPULAR" badge. Interactive Monthly vs. Annual (Save 20%) billing toggle.
- **Guided by Champions (Coaches)**: Touch-swipeable coach cards with specialty badges and consultation actions.
- **The Iron Sanctuary Gallery & Lightbox**: Responsive 2-column mobile photo grid opening into a full-screen lightbox modal with touch swipe gestures (left/right) and keyboard navigation.
- **Athlete Reviews & PRs**: Real transformation reviews with star ratings and transformation metrics tags.
- **Mobile-Optimised Pass Claim Form**: Full-width inputs with 50px touch targets, numeric keypad for phone numbers (`inputmode="tel"`), real-time validation, and instant digital biometric pass generation.
- **Floating WhatsApp Integration**: Fixed near bottom-right with 56px touch target, safe-area inset compatibility, and smart auto-retraction when viewing form buttons to prevent interface overlap.

## 📱 Tested Breakpoints

100% verified with zero horizontal overflow and ≥44px touch targets across:
- **Small Mobile**: 320px–374px
- **Standard Mobile**: 375px–430px (iPhone 13/14/15/16, Pixel, Galaxy)
- **Large Mobile**: 431px–767px
- **Tablet**: 768px–1023px (iPad, Android tablets)
- **Desktop**: 1024px & 1440px+

## 🚀 Getting Started

Clone the repository and open `index.html` in your browser, or start a local server:

```bash
# Start local server
python3 -m http.server 3000
```

Visit `http://localhost:3000` in your desktop or mobile browser.
